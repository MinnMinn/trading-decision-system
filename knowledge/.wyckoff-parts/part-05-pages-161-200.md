## Structure of this range

Pages 161–200 (file numbers) are the back half of a chapter (chapter number not visible on any page in this range; every figure is numbered "Hình 7.X," so this is chapter 7) titled implicitly by its content: **reading Wyckoff's Effort-vs-Result law bar-by-bar using a "Footprint" order-flow platform**, where "effort" = traded Volume and Delta (buy-initiated vs. sell-initiated volume), and "result" = the price bar's range/net change ("Giá: Mức chênh lệch" = price differential). The chapter defines **10 numbered "Trường hợp" (Cases)**, each a schematic combination of Volume / Delta / Price-differential direction-and-magnitude, each concluding with a bullish or bearish "Kịch bản" (scenario), followed by real Vietnamese-stock worked examples (Ví dụ 7.1–7.19) using 30-minute or 60-minute Footprint screenshots of HOSE-listed stocks (DXG, STB, PDR, VND, NVL, DCM, SSI, HAG, MSN, NLG, NKG, VNM, VIC, VHM).

Each case diagram (`[diagram]`) is a hand-drawn schematic with: a stack of ascending/descending black volume bars with an arrow above indicating volume trend intensity (single arrow = mild, more chevrons `>>>` = stronger); a green wavy trendline; one or two colored (blue/red/orange) candlesticks; and a printed formula line of the form `Vol [comparator] = D [comparator] + S [comparator]` immediately below, followed by `Nỗ Lực [comparator], Kết quả [comparator] = Tăng giá|Giảm giá`. "Nỗ Lực" = Effort, "Kết quả" = Result, "Tăng giá" = price increase (bullish), "Giảm giá" = price decrease (bearish). The comparator symbols (`<`, `=`, `>`, `>>`, `>>>`) encode relative magnitude, mirrored from a reference table (**"Bảng 7.1: Các trường hợp chính của Tape Reading Bar by Bar,"** which is on file `160.jpg` / printed p161, i.e. **one file outside this assigned range** — noted here only to explain the notation, not claimed as content of this range) with columns Khối lượng (Volume, labeled **E** = Effort), Delta (labeled **Del**), and Giá/mức chênh lệch (Price differential, labeled **R** = Result/Range).

Every worked example (Ví dụ 7.X) follows an identical prose template: bullet points for **Khối lượng** (Volume, with the actual numeric readings per bar in parentheses), **Delta** (numeric readings), **Giá** (qualitative description of the price differential/spread), and **Kết luận** or **Kịch bản** (Conclusion/Scenario — bullish or bearish, and whether "hài hòa" [harmonious] or exhibiting "phân kỳ" [divergence] / "hấp thụ" [absorption]). Each is illustrated by two screenshots: a "Tape Reading Bar by Bar" annotated candlestick+delta-histogram chart, and a "Biểu đồ Footprint" (Footprint chart) showing the raw per-price-level order-flow ladder (Volume/Delta/ratio figures at each traded price level for each bar) — these ladder screenshots are extremely dense numeric grids; I summarize them as `[diagram]` supporting evidence rather than re-transcribing every cell, since the accompanying prose already states the same aggregate Volume/Delta figures that the ladder is built from.
