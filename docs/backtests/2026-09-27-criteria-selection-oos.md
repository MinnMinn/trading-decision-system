# Pilot selection by criteria (ADR 0008) — 2026-09-27

_`scripts/rank-setups.py` (mode `criteria-oos6m`). A system is **ENABLED only if it passes every criterion of its horizon on its in-sample window AND on its held-out OOS window** (`docs/architecture/selection-criteria.json` v1, decided 2026-09-26). Every system that passes is enabled; there is no ranking, no top-N, no per-slot winner, no coverage fallback and no runner-up substitution. A horizon with no passing system trades nothing. Returns are account-level, net of costs, live-parity 1 % sizing; each side of the split is its own fresh $10,000 account. Trades belong to a window by ENTRY time. Every number is a code proxy over research history._
