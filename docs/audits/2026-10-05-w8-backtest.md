## Findings

- **OBSERVED:** W8 removes 70 % of v1 structures and 41 % of adopted-set structures; admitted trades fall 60 % (v1) and 46 % (ad).
- **OBSERVED:** mean net R is negative in every variant and every timeframe. W8 makes the 15m totals worse (both bases) and the 1H totals less negative (both bases); 4H moves in opposite directions by base on 14–35 trades.
- **OBSERVED:** the few positive cells (e.g. DE40 15m/1H v1+W8, XAGUSD 1H ad+W8, XAUUSD 4H ad/ad+W8) hold 3–39 taken trades each; none is consistent across instruments or bases.
- **INFERRED:** W8 is a fidelity correction (the book's box rule), not an edge. It does not turn mechanical WYCKOFF-BOOK into a candidate for the FTMO goal; no variant here would pass the pilot criteria (docs/architecture/selection-criteria.json) on this evidence.
- **INFERRED:** 1H improving while 15m worsens is within what 24 small cells produce by chance after 4 variants; no significance test was run and none is claimed.

## What "on" means after this run

- `fx_w8_choch_in_box` is an engine key (default False = v1). Existing results, the live runner (which enables no Wyckoff system: docs/architecture/pilot-selection.json `setups` is empty) and the frozen fund-search plan (`docs/experiments/fund-search/plan.json`, plan hash in research-ledger.json) are unchanged. Adding W8 to that plan's `adopted_f_keys` would change a pre-registered experiment after it was defined, so it is not done here.
- Making W8 the default of the Wyckoff method (wyckoff_rules.PARAMS, which the chart also reads per ADR 0009) is a Trading-System-version change (§47/§59) for any future Wyckoff system; it is left to the owner's decision with these numbers.
