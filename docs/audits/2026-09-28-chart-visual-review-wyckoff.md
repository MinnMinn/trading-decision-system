## 0. What the images show, in one paragraph

**None of the 27 Wyckoff charts draws any Wyckoff element.** No trading-range border, no phase band, no event flag. Each legend still advertises "trading range border (AR / SC)", "phases A–E" and "● Wyckoff events". To tell a rendering failure from an empty read, I checked the page data. In `scalping.html`, all 27 tiers carry `"wy": {"tr": null, "events": [], "phases": []}`. `data/live/narrative/scalping.json` (`updated` 2026-09-27T05:30Z) records `"structure": "chưa xác lập", "phase": null` for all 9 symbols; the 4H context read is dated 2026-09-26T07:15Z. So the blank charts faithfully show a read of "not established". The chart never *says* so, though. And the read itself is stale and misses structure that is plainly visible (see §2). Two other items do appear on the Wyckoff lane. The first is an ICT-owned invalidation line ("invalidated · ict …") on 6 entry charts. The second, on the BTC entry chart, is two clipped orange axis tags ("77,534" and a cut-off "…,425"). These are Wyckoff anchor levels from `data/live/anchors.scalping.json`: BTC SC 76,676 / AR 77,425 / UA 77,534 / Shakeout 76,423, ETH SC 2,405.85 / AR 2,444.45 / UA 2,505.14 / Shakeout 2,387.33, and SOL SC 98.5 / AR 100.37 / UA 100.85 / Shakeout 98.06, all with `time: null`. They belong to an old structure far below price, and they contradict the narrative's own "not established".

Time coverage visible in the images:
- bias 4H: the title says 07-29 → 09-27 04:00, but the default view shows only about 09-01 → 09-27 04:00.
- structure 1H: the title says 09-07 → 09-27 05:00; the view shows about 09-21 → 09-27 05:00.
- entry 15m: the title says 09-22 10:00 → 09-28 09:45; the view shows about 09-26 18:00 → 09-28 09:45.

The two higher tiers therefore end about 28–29 h before the entry tier. They miss the 09-28 sell-off, which is the largest move on every entry chart.

Context that limits the risk: on this page the Wyckoff lane is analysis-only. The page data has `"engaged": ["ict"]`, and the badge reads "analysis only — not traded by the active system, does not count toward confluence". ## 3. Recommendations (for the owner; not implemented)

1. When `wy.tr` is null and there are no events or phases, draw an explicit note, e.g. "Wyckoff: structure not established · read 09-27 05:30Z", and remove the TR/phase/event legend entries (D1).
2. Refresh the bias and structure tiers to the same last candle as the entry tier, and stamp the read time on each chart. Flag the read as stale when price has left the read's range, or when more than N bars have closed since the read (D2).
3. Widen the Wyckoff read beyond 96 × 15m so that it evaluates the 4H/1H Phase A that is plainly present (D3).
4. Drop, or time-stamp, the SC/AR/UA/Shakeout anchors that contradict the current read. Never draw a `time: null` Wyckoff anchor edge-to-edge (D4).
5. Relabel the untriggered invalidation line (e.g. "invalidation · ict 119.77") and verify the triggered state against the entry tier's closes (D5).
6. Fix the tick-label overprint and use instrument tick-size precision on the price axis (D7).
