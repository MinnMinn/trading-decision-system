# ICT chart visual review — 2026-09-28

Reviewer: an independent ICT chart reviewer, working only from the images. It did not read `docs/audits/2026-09-28-method-fidelity.md`.
Scope: the 51 ICT-lane screenshots from `scripts/capture-charts.mjs`. That is `out-cfd-day/*.ict.png` (24 images: 8 CFD symbols × 1D bias / 4H structure / 1H entry) and `out-scalping/*.ict.png` (27 images: 9 crypto symbols × 4H bias / 1H structure / 15m entry).
Method: every image was opened. Prices and times were read off the axes. Each capture is about 1100×490 px, so a price read is accurate to roughly ±0.3 % of the visible range. Where a read was not possible it says "cannot judge". `scripts/chart.js` was read only to decode what a line style means (cited as `chart.js:<line>`). It was never used to excuse a drawing.
Sources cited: `knowledge/ict/core-a.md` (A), `knowledge/ict/core-b.md` (B), `knowledge/ict/models.md` (M), `knowledge/ict/mentorship-2024.md` (MT).

Verdict key: **OK** = drawn to spec. **minor** = cosmetic, or a defect that would not change a read. **wrong** = at least one element misstates structure or liquidity, or is stale in a way that would mislead a trading read.
